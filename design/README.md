# Design handoff

Put the Claude Design handoff for the Modz Tech mockup and design system in this folder.
The site is built to match these files.

Suggested layout:

- `design-system/`: colours, fonts, type scale, radii, shadows, component specs
- `mobile/`: mobile page mockups (Home, Shop, Search, Product, Cart, Checkout, Order confirmed, Track order, Log in / Sign up, Contact, 404)
- `desktop/`: desktop mockups (Home, Shop, Product, Cart, Checkout)
- `assets/`: logo, icons, sample images

Any format works (HTML, images, PDF, Markdown). If a file disagrees with the written requirements, the design files win for visuals.
